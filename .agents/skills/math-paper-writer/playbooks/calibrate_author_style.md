# Playbook: Author Style Calibration

1. Identify the calibration corpus and whether it represents the target author, venue, or project.
2. Read `references/style_calibration.md`.
3. Exclude text known to contain mathematical, citation, or reproducibility errors.
4. Profile stable style dimensions: sentence rhythm, paragraph shape, signposting, theorem/proof roadmaps, citation integration, notation exposition, experiment narration, and hedging.
5. Mark unsafe features that must not be imitated.
6. Fill `assets/style_profile_template.md` when the style will be reused.
7. Apply style only after the relevant mathematical and claim-evidence checks pass.
8. Report any conflict between style preservation and accuracy.

Output order:

1. Corpus and scope
2. Stable style features
3. Unsafe features
4. Revision rules
5. Calibrated revision or sample
6. Accuracy/style conflicts
