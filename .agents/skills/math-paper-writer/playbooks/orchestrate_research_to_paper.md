# Playbook: Research-to-Paper Orchestration

1. Read `references/research_state_protocol.md` and `references/skill_integration.md`.
2. Identify the paper object being advanced: question, theorem, proof, experiment, related work, draft section, response letter, or submission package.
3. Decide whether an external skill is needed for discovery, bibliography, visualization, review, slides, or style.
4. If using an external skill, read its `SKILL.md`, load only relevant references, and record the handoff.
5. Convert raw research material into manuscript objects: claims, result cards, proof obligations, citation obligations, experiment obligations, and limitations.
6. Update or create state files only when useful and consistent with the project.
7. Draft or revise from verified objects; mark unverified objects instead of smoothing over them.
8. End with next safe actions.

Output order:

1. Current paper state
2. External skills used or deliberately skipped
3. Manuscript objects created or updated
4. Verification status
5. Draft/revision when requested
6. Next safe actions
