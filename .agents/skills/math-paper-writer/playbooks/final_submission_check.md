# Playbook: Final Submission Check

1. Run six-pass proofreading using `assets/six_pass_review_template.md`.
2. Run optional deterministic scripts if files are available.
3. Check theorem/lemma/proof labels and references.
4. Check equation punctuation and display math.
5. Check all citations and bibliography entries.
6. Check figures, tables, captions, and axis labels.
7. Check abstract/introduction/conclusion consistency.
8. Check acknowledgements and author names.
9. Produce a prioritized risk report.

Do not silently fix mathematically significant issues. Report them first.
