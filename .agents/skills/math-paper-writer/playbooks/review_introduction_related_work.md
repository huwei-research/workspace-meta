# Playbook: Introduction and Related-Work Review

1. Reconstruct the paper's thesis in one sentence.
2. Identify the reader and the problem origin.
3. Check whether the first page invites the reader or starts with avoidable formalism.
4. Check whether prior work is integrated into the story.
5. For each citation cluster, ask what narrative function it serves.
6. Identify the explicit gap.
7. Match every contribution claim to a theorem, algorithm, experiment, or example.
8. Flag overclaimed novelty and unsupported comparisons.
9. Check whether related work is organized by ideas rather than a citation dump.
10. Suggest a new paragraph sequence if the current one does not guide the reader.

Output:

1. Reconstructed thesis
2. Reader-path diagnosis
3. Prior-work integration diagnosis
4. Contribution contract table
5. Unsupported or overbroad claims
6. Suggested rewrite structure
7. Revised sample paragraphs if requested
