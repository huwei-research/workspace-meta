# Playbook: Revise an Existing Manuscript

1. Identify whether the user wants local polish, structural revision, or mathematical audit.
2. Preserve mathematical content unless a problem is found.
3. Separate edits into: mathematical, structural, expository, stylistic, production.
4. For local edits, keep labels, citations, macros, and notation stable.
5. For structural edits, propose the new order before rewriting large sections.
6. For proof edits, run proof audit first.
7. For introduction edits, run story audit first.
8. For experiment edits, run reproducibility audit first.
9. Produce a change log.

Output:

1. Diagnosis
2. Revised text or patch plan
3. Change log
4. Mathematical risks
5. Remaining questions
