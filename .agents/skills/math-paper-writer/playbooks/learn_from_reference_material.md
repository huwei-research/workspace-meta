# Playbook: Learn from Reference Material

Use this playbook when the user provides writing guides, reviewer reports,
venue instructions, style samples, or exemplary papers and asks the skill to
adapt.

## Procedure

1. Identify the material type: guide, exemplar paper, reviewer report, venue
   instruction, author sample, or field convention.
2. Read only the parts relevant to the current task unless the user requests a
   full close reading.
3. Extract operational guidance:
   - writing principle;
   - review question;
   - terminology or notation convention;
   - evidence requirement;
   - formatting or production requirement.
4. Apply the guidance through this skill's existing objects: reader contract,
   result card, claim ledger, source card, experiment ledger, style profile, or
   gate review.
5. Keep private working notes concise. Do not expose a long learning log unless
   the user asks for one.
6. If the guidance conflicts with mathematical truth, source accuracy, or
   reproducibility, reject or narrow the guidance.

## Output

For ordinary tasks, report only:

1. reference material used;
2. principles applied;
3. manuscript changes or review findings;
4. remaining uncertainty.

For explicit learning tasks, use `assets/reference_calibration_notes_template.md`
if a durable note is useful.

## Anti-patterns

- Showing the user a large extraction ledger when they asked for a better
  manuscript.
- Treating style advice as permission to remove assumptions or citations.
- Importing field-specific conventions into a different discipline without
  checking local norms.
- Keeping source notes that are not tied to an operational rule.
